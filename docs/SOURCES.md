- [UIDAI service information](https://www.uidai.gov.in/)
- [Sarathi driving-licence services](https://sarathi.parivahan.gov.in/sarathiservice/stateSelection.do)
- [Parivahan learner-licence application guidance](https://parivahan.gov.in/parivahan/en/content/how-apply-learners-license)
- [PAN application portal](https://www.onlineservices.nsdl.com/paam/endUserRegisterContact.html)
- [Passport Seva](https://www.passportindia.gov.in/)
- [Election Commission voter services](https://voters.eci.gov.in/)
- [AP MeeSeva](https://ap.meeseva.gov.in/)
- [e-Shram](https://eshram.gov.in/)
- [National Career Service](https://www.ncs.gov.in/)
- [DigiLocker](https://www.digilocker.gov.in/)
- [EPFO](https://www.epfindia.gov.in/)
- [ESIC](https://www.esic.gov.in/)

The prototype opens these routes only when a user chooses to continue. It does not integrate their APIs or submit personal information.
