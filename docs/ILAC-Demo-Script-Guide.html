If you get stuck

Cannot see a menu? Use the account listed for the step; each role has different access.

Household autofill? Use the persona helper in Personal & work details first, then Fill P-01/P-03 household. New mandatory C1 fields must also be answered.

No seat callback? Create the SK-01 referral first; already-confirmed cases disappear from the awaiting-seat list.

No sync? Download the visit online, capture offline, then turn Airplane mode off. Keep the same tab for field-device work.

Already used a person? Existing registrations can trigger duplicates. Continue the saved run or intentionally start a fresh rehearsal via Reset; reset clears changes.

No acknowledgement dialog? Use Gateway and the existing case records. Do not repeat the referral submission merely to recreate the dialog.
